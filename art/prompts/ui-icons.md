# ui-icons

Reference: art/selected/style-frame.png (except the initial style frame).

Square transparent 4 column by 2 row sprite atlas, eight separate centered game icons in reading order: dink ball arc, fast drive arrow with ball, drop ball arc, high lob arc, smash downward ball, trophy, wifi, pickleball paddle. Uniform evergreen line weight, rounded caps, cream and clay accent fills, clean hand-cut sports-club design. Equal cell size and generous transparent padding. No text, labels, border, numbers or shadows.

Match docs/art-bible.md: rounded matte forms, upper-left soft key, palette of evergreen/sage/cream/clay/violet, restrained grain. Reject stray text, warped faces, extra fingers, inconsistent style. Four independent variants, explicit review before selection.
